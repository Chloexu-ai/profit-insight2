## 3. 指标字典

### 3.1 原始指标（metrics）

| 字段 key | 名称 | 说明 |
|---|---|---|
| `amount` | 金额 | 管报金额列，按科目+数据类型归集到下列指标 |
| `revenue` | 实际收入 | 可由 `amount` 归集得到，也兼容旧格式直接导入 |
| `cost` | 实际成本 | 可由 `amount` 归集得到，也兼容旧格式直接导入 |
| `budget` | 预算收入 | 可由 `amount` 归集得到，也兼容旧格式直接导入 |
| `budget_cost` | 预算成本 | 可由 `amount` 归集得到，也兼容旧格式直接导入 |

### 3.2 派生指标（derived）

| 字段 key | 名称 | 计算口径 |
|---|---|---|
| `actual_profit` | 实际利润 | 实际收入 - 实际成本 |
| `budget_profit` | 预算利润 | 预算收入 - 预算成本 |
| `profit_variance` | 利润差异 | 实际利润 - 预算利润 |
| `revenue_variance` | 收入差异 | 实际收入 - 预算收入 |
| `margin` | 利润率 | 实际利润 / 实际收入 |

## 4. 归集口径（amount → 收入/成本/预算）

导入「金额 + 科目 + 数据类型」时，按下列规则自动归集，使管报格式与旧指标口径共存。

### 4.1 数据类型 → 预算/实际角色（`dataTypeRole`）

| 原写法 | 标准值 |
|---|---|
| `实际数` | actual |
| `预算数` | budget |
| `预测数` | forecast |

### 4.2 科目 → 收入/成本角色（`subjectRole`）

| 角色 | 科目 |
|---|---|
| revenue | `销售收入` / `发货GMV` / `买家实付运费收入` / `物流补贴收入` / `订单量` / `销量` |
| cost | `产品成本-内核法` / `采购成本` / `中台结算成本` / `综合头程成本` / `空运成本` / `赠品成本` / `综合税负` / `销售费用` / `管理费用` / `财务费用` / `营业税金及附加` / `企业所得税` |

> 归集逻辑：科目属于 `revenue` 组且数据类型为「实际数」→ 计入实际收入；属于 `cost` 组且为「实际数」→ 计入实际成本；数据类型为「预算数」→ 对应计入预算收入/预算成本。未命中科目不归集，仅保留 `amount` 原值。

## 6. 旧格式兼容

- 旧模板（期间 / 区域 / 产品线 / 渠道 / 实际收入 / 实际成本 / 预算收入 / 预算成本）仍可导入。
- `期间` 同时填充 `month` 与 `period`，保证旧看板「利润趋势（按期间）」不失效。
- `区域`/`产品线` 走旧口径键 `region`/`product`，不影响管报维度统计。

## 8. 数据视图权限（科目级可见范围）

由 `js/config.js` 的 `PA_DATA_VIEWS` 定义，M1 预览 / M2 问数 / M3 看板 / M4 推送检查统一通过 `PA.applyDataView()` 过滤。

| 视图 | 可见科目范围 | 适用 |
|---|---|---|
| 管理层视图 | 全部科目（含净利润） | 可见全部科目：含真实产品成本、各项费用直至营业利润、净利润。 |
| 业务端视图 | 产品成本-内核法 → 销售毛利-内核法 | 仅可见「产品成本-内核法」至「销售毛利-内核法」区间的科目，隐藏净利润等敏感科目。 |

- 角色默认：`owner`→管理层，`editor`/`viewer`→业务端；成员可在 M5 数据权限中心单独指定。
- 主数据字典可由 M6 在线维护并写入云端 `pa_masterdata`（按空间隔离），加载时覆盖系统默认字典。
